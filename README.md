# Flight-Programming MatLab
To model and test our algorithm before introducing RocketPy simulation.

To open, first open the branch via Git Desktop. 

Instead of VisualStudioCode, you can go to "Show in Explorer" to see the project's location and open the Simulink model (with the extension .slx). It may prompt open the default Matlab workspace first; just open the .slx file in the side bar to open Simulink.

Alternatively, open Matlab independently and open the repositiory through their file explorer, then follow the remaining instructions above.
